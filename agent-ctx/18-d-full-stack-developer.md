## Задача
Три ворк-айтема для MVP-приложений ПРЯМО (оверлей на единственном маршруте `/`):
1. localStorage-персистентность (hydration-safe): история поездок пассажира + заработок водителя (merge, не overwrite), версионируемые ключи v1.
2. Живой сурж-индикатор в форме заказа пассажира (данные demand:state движка, кап ×1,5).
3. Мини-карта в активной поездке водителя (переиспользование CityMap).

## Ключевое инженерное решение
ТЗ требовало «Load inside useEffect», но новый линтер проекта `react-hooks/set-state-in-effect` (React Compiler ruleset) запрещает синхронный setState в теле эффекта. Решение: ленивые инициализаторы `useState(() => load…)`. Это безопасно для гидратации ПО КОНСТРУКЦИИ: оверлей MVP закрыт при SSR и гидратации (`open=false`), приложения монтируются только на клиенте — проверено по SSR-HTML (`приложение пассажира` / «ПРЯМО MVP» отсутствуют в выдаче, есть только кнопка «MVP-приложение»). Запись — эффектами (благое направление «обнови внешнюю систему»).
