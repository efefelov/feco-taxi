    18→## 1.2 Боли ВОДИТЕЛЕЙ (наш атакующий вектор)
    19→1. **Комиссия 24%+ (фактически 30–50% потерь)**: официальная комиссия ~24%, но с «опциями», платными подписками таксопарков, штрафами и волатильностью до 37% реальная потеря — до половины чека. Судебная практика: из 520 575 ₽ дохода водителя удержано 104 336 ₽ (≈20% чистыми комиссиями, до вычета прочего).
    20→2. **Неадекватный рейтинг**: 1 звезда от пассажира = ~10 пятёрок по весу; рейтинг «молчит» (не видно, за что снижение); старые оценки не затухают; нет защиты от несправедливых оценок.
    21→3. **Баллы приоритета / «карточка качества»**: непрозрачный алгоритм распределения заказов; за отказ от невыгодного заказа — понижение приоритета → меньше заказов → порочный круг. Отзывы водителей: «Решает не приоритет, решает карточка качества... оценка и качество заказов» (forum.taxi).
    22→4. **Непонятный спрос**: «зоны повышенного спроса» без цифр — водитель едет в зону и ждёт заказ 10 минут. Нет прогноза спроса, нет данных по ликвидности зон.
    23→5. **Привязка к Яндекс.Навигатору**: нет выбора навигатора (2GIS/OSM); проблемы с GPS-сигналом в тоннелях/паркингах → срыв заказа → штраф.
    24→6. **Непрозрачное ценообразование**: водитель не видит, сколько заплатил пассажир; «оптимизация» цен алгоритмом в realtime.
    25→7. **Штрафы и блокировки без суда**: автоматические списания, «поддержка» отвечает шаблонами, бонусы не зачисляются (irecommend, otzovik).
    26→8. **Невыгодные тарифы в час пик**: алгоритм режет заработок при surge — водитель получает долю без коэффициента.

    48→## 2.1 Ключевой принцип
    49→Комиссия ≤ 8% ИЛИ подписка. Деньги делаем НЕ на комиссии водителя, а на экосистеме вокруг поездки.
    50→
    51→## 2.2 Потоки доходов (по приоритету)
    52→1. **Подписка водителя «ПРЯМО Pro» — 1 990 ₽/мес**: 0% комиссии, приоритет в ленте, аналитика. Аналог: Deliveroo/Uber в других юрисдикциях. При среднем чеке 450 ₽ × 20 заказов/день × 26 дней = 234 000 ₽/мес оборота: наша комиссия 8% = 18 720 ₽ против подписки 1 990 ₽ — водитель видит выгоду мгновенно.
    53→2. **Комиссия 8% flat** (без подписки): без скрытых опций, волатильность = 0, фиксируется в оферте. (Яндекс: 24%+)
    54→3. **Корпоративные счета (B2B)**: +2% сервисный сбор, но SLA, отчётность, лимиты. Рынок корп. такси ~15% поездок.
    55→4. **Транзакционный экосистемный доход**:
    56→   - Топливная карта «ПРЯМО Топливо» (ребейт с АЗС 1–2% с оборота топлива водителей)
    57→   - ТО/шиномонтаж/мойка партнёров (реферальная модель)
    58→   - Лизинг/страхование для водителей (комиссия партнёра)
    59→5. **Реклама и гео-промо**: рестораны, отели, «по пути» промо — CPM/CPA, БЕЗ деградации UX (макс 1 блок).
    60→6. **Пассажирский сервисный сбор 0%**: рост заказов = рост подписчиков-водителей. Платные фичи пассажира: выбор класса «Комфорт гарантирован», детский бустер, «тихий водитель» — микротарифы.
    61→
    62→## 2.3 Unit-экономика (модель на 1 город, год 1)
    63→- Допущения: 500 000 жителей города-миллионника, 60 000 поездок/сутки всего рынка, цель 10% → 6 000 поездок/сутки, средний чек 450 ₽
    64→- Оборот: 6 000 × 450 × 365 = 985,5 млн ₽/год
    65→- Наш валовый доход: 8% × 60% поездок (без подписки) + подписки: ≈ 47,3 млн ₽ + 40% водителей на Pro (400 × 1990 × 12 = 9,55 млн) ≈ 57 млн ₽/год
    66→- Издержки года 1 (команда 12 чел, маркетинг, серверы): ~85–95 млн ₽ → breakeven на год 2 при 15% рынка
    67→- KPI-стратегия: CAC водителя < 2 000 ₽, LTV > 80 000 ₽ (водитель работает 14 мес, маржа с Pro-водителя 1 200 ₽/мес)

    69→## 2.4 Дифференциаторы продукта (то, что «убивает»)
    70→1. **Прозрачный чек**: пассажир и водитель видят ОДНУ цену; водитель видит свою выплату ДО принятия заказа
    71→2. **Рейтинг 2.0**: многомерный (пунктуальность/вождение/чистота/комфорт), затухание 90 дней, защита от разовой несправедливой 1★ (медиана вместо среднего, вес по числу поездок)
    72→3. **Живая карта спроса**: реальные цифры ожидания/заказов по зонам, прогноз на 2 часа
    73→4. **Аукцион заказов против очереди с приоритетами**: заказ уходит тому, кто первый ВЗЯЛ, без «карточки качества»; за отказ НЕТ штрафа
    74→5. **Любой навигатор**: 2GIS / Яндекс / OsmAnd — выбор водителя
    75→6. **Офлайн-устойчивость**: заказ живёт в очереди 15 мин без GPS; SMS-fallback
    76→7. **Чаевые 100%** водителю, в один клик
    77→8. **Surge-кап**: коэффициент ≤ 1.5 и виден ДО заказа; драйверу — полная доля с коэффициентом

   108→## 3.4 КОНТРАКТ WebSocket (порт 3003, ride-engine) — ОБЯЗАТЕЛЕН ДЛЯ ИНТЕГРАЦИИ
   109→Frontend: `io('/', { path: '/socket.io', query: { XTransformPort: '3003' } })` — НИКОГДА не `http://localhost:3003`.
   110→
   111→### Client → Server
   112→- `driver:join` {} → в ответ: `feed:state`, `demand:state`, `stats:live`
   113→- `passenger:join` {}
   114→- `passenger:book` { from: string, to: string, tariffId: string } → поиск водителя 6–12 сек → `ride:state` (searching→arriving→onboard→completed)
   115→- `ride:rate` { rideId: string, axes: { punctuality: 1..5, driving: 1..5, comfort: 1..5, cleanliness: 1..5 }, tip: number }
   116→- `driver:accept` { orderId: string } → если заказ ещё доступен: удалить из общей ленты (broadcast `orders:remove` reason=taken), начать жизненный цикл поездки для этого сокета
   117→- `driver:go-online` {} / `driver:go-offline` {}
   118→
   119→### Server → Client
   120→- `feed:state` { orders: OrderDTO[] }
   121→- `orders:new` { order: OrderDTO } (каждые 4–9 сек, максимум 8 в ленте)
   122→- `orders:remove` { id, reason: 'taken'|'expired' } (заказ живёт 35–60 сек)
   123→- `demand:state` { zones: ZoneDTO[], updatedAt }
   124→- `stats:live` { activeDrivers, onlineDrivers, ordersPerHour, avgWaitSec, completedToday, grossTodayRub }
   125→- `ride:state` { ride: RideDTO } — только сокету-владельцу поездки
   126→- `ride:completed` { ride: RideDTO, receipt: { price, driverPayout, commissionRub, tip } }
   127→- `driver:earnings` { today: { gross, payout, commission, rides, hoursOnline }, lastRides: RideDTO[] }
   128→
   129→### DTO
   130→OrderDTO: { id, from: {label, zoneId}, to: {label, zoneId}, distanceKm, durationMin, tariff: {id, name, multiplier}, priceTotal, driverPayout, commissionRub, surge, createdAt, expiresAt }
   131→ZoneDTO: { id, name, x, y, demand: 0..100, surge: 1.0..1.5, waitingDrivers, ordersWaiting, avgWaitMin }
   132→RideDTO: { id, status: 'searching'|'arriving'|'onboard'|'completed', driver: {name, initials, car, plate, rating, rides}, from, to, distanceKm, etaMin, progress: 0..1, priceTotal, driverPayout, tariffName, startedAt }
   133→
   134→Геометрия карты: нормированные координаты x: 0..1000, y: 0..600. Зоны: Центр(500,300), Север(500,100), Юг(500,500), Запад(200,300), Восток(800,300), Аэропорт(900,80).
